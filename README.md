# 👨‍🍳 بوابة فرص الشيف المحترف (Executive Chef Job Portal)

منصة ويب متكاملة، فائقة السرعة والاستجابة، مخصصة لفرص العمل القيادية للشيفات (شيف عمومي، مدير مطبخ، سو شيف، رئيس قسم مشويات وسخن) مع فلاتر ذكية مصممة خصيصاً لاحتياجات أصحاب الخبرات الكبيرة ونطاق سكن محافظة الشرقية (الزقازيق).

---

## 🌟 مميزات المنصة

- **⚡ محرك بحث وتصفية فوري ومتقدم:**
  - بحث نصي فوري بالكلمات المفتاحية (المسمى، اسم المنشأة، المنطقة، المزايا).
  - كبسولات تصفية سريعة بنقرة واحدة (رواتب تكسر الـ 20 ألف، إدارة وإشراف، داخل الزقازيق، العاشر من رمضان وبدر، متوفر سكن).
  - قوائم تصفية دقيقة (نطاق الراتب، النطاق الجغرافي، التخصص الوظيفي).
  - خيارات ترتيب ذكية (الأعلى تطابقاً مع خبرة وسن الشيف، الراتب الأعلى، الأقرب للسكن، الأحدث).
- **⭐ نظام حفظ في المفضلة (LocalStorage):**
  - حفظ الفرص المميزة ومراجعتها في أي وقت بدون الحاجة لاتصال أو تسجيل دخول.
- **💬 رسائل تقديم ذكية ومخصصة لكل وظيفة:**
  - زر بنقرة واحدة لنسخ رسالة تقديم احترافية للواتساب تبرز خبرة الشيف (+15 سنة) في إدارة المطابخ وضبط التكاليف بدون ذكر تفاصيل سكن غير مرغوب فيها، مع الاستفسار الدقيق عن الراتب الصافي والسكن والمواصلات.
- **🗺️ تكامل مباشر مع خرائط Google:**
  - حساب المسار وخط المواصلات مباشرة من الزقازيق إلى موقع العمل.
- **💡 دليل وخطة الشيف للتفاوض والمقابلات:**
  - نصائح لكسر حاجز الـ 20 ألف جنيه بالمقابلات الفنية.
  - أهم الأسئلة الحاسمة لصاحب العمل قبل توقيع العقد.
  - ملخص سيرة ذاتية سريع للشيف جاهز للنسخ بنقرة واحدة.
- **🚀 بدون أي تبعيات أو حزم (Zero-Dependency):**
  - يعمل بملف واحد نظيف وخفيف جداً `index.html`.
  - متوافق 100% مع الهواتف الذكية وأجهزة الكمبيوتر (PWA Ready).

## 🚀 طرق النشر والاستضافة (Deployment)

### 1. النشر المباشر عبر Vercel (موصى به مجاناً)
1. افتح حسابك على [Vercel](https://vercel.com).
2. اختر **Add New → Project** ثم اختر مستودعك `mmahmouudd/pup`.
3. اترك الإعدادات الافتراضية:
   - **Framework Preset**: Other
   - **Root Directory**: `./` (الجذر)
   - لا حاجة لأي Build Command.
4. اضغط **Deploy**؛ سيصبح الموقع متاحاً على رابط عالمي سريع ومجاني (مثل `pup.vercel.app`) مع شهادة SSL تلقائية.

### 2. النشر عبر GitHub Pages
1. ادخل على مستودعك على GitHub: `https://github.com/mmahmouudd/pup`.
2. ادخل إلى **Settings** ثم من القائمة الجانبية اختر **Pages**.
3. تحت **Branch**، اختر فرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. خلال دقيقة واحدة سيكون موقعك متاحاً على الرابط:  
   `https://mmahmouudd.github.io/pup/`

## 🛠️ تحديث وإضافة فرص جديدة
قاعدة البيانات مخزنة داخل مصفوفة `JOBS_DATA` في نهاية ملف `index.html`. يمكنك إضافة أو تعديل أي وظيفة بسهولة عبر كتابة بياناتها بنفس نسق الكائنات الموجودة.
