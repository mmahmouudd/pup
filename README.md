# تقرير فرص الشيف

موقع ثابت يعمل بملف HTML واحد ولا يحتاج إلى تثبيت حزم أو إعدادات بناء.

## الرفع على GitHub
1. أنشئ مستودعًا جديدًا على GitHub.
2. اختر **Add file → Upload files**.
3. ارفع ملفي `index.html` و`README.md` الموجودين داخل هذا المجلد إلى **جذر المستودع** مباشرةً، وليس داخل مجلد إضافي.
4. اضغط **Commit changes**.

## النشر على Vercel
1. من لوحة Vercel اختر **Add New → Project**، واستورد مستودع GitHub الذي رفعت عليه الملفات.
2. اترك **Framework Preset** على Other، واجعل **Root Directory** هو جذر المستودع. لا تحتاج إلى Build Command.
3. اضغط **Deploy**، وبعد اكتمال النشر افتح رابط الموقع وتأكد أنه متاح بدون تسجيل دخول. إذا طلب تسجيل الدخول، راجع إعدادات Deployment Protection في المشروع.

## تحديث التقرير
عدّل ملف `index.html` ثم ارفع التعديل إلى GitHub. المحتوى ملخص بحث ثابت بتاريخ ٥ نوفمبر ٢٠٢٦؛ لا يتم تحديث إعلانات الوظائف تلقائيًا، وقد تتغير حالتها وبياناتها.
